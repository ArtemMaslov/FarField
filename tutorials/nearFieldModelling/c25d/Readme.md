Attention! To run this case you need foam-extend-5.0 from https://sourceforge.net/projects/foam-extend/. Not OpenFOAM 2312 from www.openfoam.com. But to run FarField you need OpenFOAM 2312.

c25d is a model from the 2nd NASA sonic boom workshop (https://lbpw.larc.nasa.gov/sbpw2/). In the numerical simulation was used mesh from the workshop.

To run case:
1. unzip constant/polyMesh.zip
1. run dbnsFoam
